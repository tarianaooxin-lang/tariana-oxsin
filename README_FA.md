# تاریانا اوکسین — Backend v2

این نسخه برای استفاده واقعی چند گوشی آماده شده است: رابط موبایل قبلی حفظ شده، اما ثبت‌نام، ورود، پروفایل، قیمت‌ها، مشتری‌ها و سفارش‌ها از طریق Backend و PostgreSQL ذخیره می‌شوند. کاتالوگ 437 قلم نسخه پروژه حفظ شده و گروه «آملون» نیز در داده‌ها وجود دارد.

## اجرای تست محلی

نیاز: Node.js 20+

```bash
npm install
npm test
npm start
```

سپس: `http://localhost:10000`

اگر `DATABASE_URL` تنظیم نشده باشد، برای تست از `pg-mem` استفاده می‌شود؛ برای استقرار واقعی حتماً PostgreSQL متصل کنید.

## Render

فایل `render.yaml` برای Blueprint آماده شده است. در Render می‌توانید Blueprint را از این مخزن بسازید. Web Service باید روی `0.0.0.0` و `PORT` محیط اجرا گوش دهد؛ این پروژه همین کار را می‌کند. Render برای Web Service یک URL عمومی `onrender.com` می‌دهد.

### متغیرهای محیطی
- `DATABASE_URL`: توسط Render Postgres
- `JWT_SECRET`: توسط Render تولید می‌شود
- `ADMIN_INITIAL_PASSWORD`: فقط برای اولین ساخت مدیر؛ پیشنهاد: یک رمز قوی بگذارید.

## ورود مدیر
نام کاربری اولیه: `admin`
رمز اولیه: مقدار `ADMIN_INITIAL_PASSWORD`؛ اگر آن متغیر را تنظیم نکنید در تست محلی `1234` است. بعد از ورود از «تنظیمات» رمز را تغییر دهید.

## تست‌ها
اسکریپت `tests/smoke.js` مسیرهای سلامت، کاتالوگ، ثبت‌نام، ورود، پروفایل، تغییر قیمت، ماندگاری قیمت، تأیید مشتری، ثبت سفارش و تغییر رمز مدیر را تست می‌کند.
